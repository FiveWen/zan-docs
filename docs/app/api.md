# 版本与能力状态

本页用于区分已发布能力、现有兼容实现和正在设计的协议。只有标记为“已发布”且双方确认版本的内容，才可作为生产接入合同。

| 范围 | 状态 | 说明 |
|---|---|---|
| 北仑 CP2 登录、分享、扫码、定位 | 已发布基线 | `@zan/embed-bridge@0.1.0-canary.2`，由我方适配 |
| 平台型 App 通用探测与同步会话提交 | 开发中 | 本地代码已实现部分能力，尚未发布 |
| UniApp/UniAppX/原生消息传输 | 现有兼容实现 | 需逐 App 核对消息包装，不是统一外部合同 |
| 第三方 App 统一登录协议 | 待发布 | 当前为接入阻塞项 |
| 导航、分享、扫码、支付 v1 回调协议 | 待设计/发布 | v0 消息可用于兼容性评估，不承诺确定回调 |

## 状态定义

- **已发布基线**：代码已发布，但 canary 仍需在指定项目中联调；
- **现有兼容实现**：历史代码真实存在，不代表适用于所有新 App；
- **开发中**：代码尚未发布，不能作为第三方生产合同；
- **待发布**：语义已明确但 wire 字段未定稿，App 方不得自行扩展为生产协议。

每次正式发布必须记录包版本、商城版本、支持的 App、协议版本、能力矩阵和兼容性变更。
