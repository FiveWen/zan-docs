# 第三方 App 接入商城 H5

本栏目面向第三方 App 开发团队。聚宝赞提供商城页面和接入协议，App 方负责 WebView 容器、宿主声明以及所需原生能力的实现。

> 当前状态：统一对外协议仍在定稿，尚未发布稳定版本。现有代码包含 UniApp、UniAppX 和原生 WebView 的兼容实现，但不能直接视为所有新 App 的正式合同。标为“待发布”的协议需双方确认版本后才能进入生产开发。

## 接入步骤

1. 向聚宝赞申请测试/生产商城域名、`siteId` 和唯一 `hostApp` key；
2. 按 [WebView 与环境约定](/app/embed-webview) 创建容器并完成宿主识别；
3. 双方确认登录凭据合同后实现 [登录协议](/app/embed-login)；
4. 按需求实现导航、分享、扫码和支付能力；
5. 使用测试站点完成真机联调、异常场景和历史网页回归；
6. 双方确认协议版本、能力矩阵及发布时间后上线。

## 商城入口

```text
https://<商城域名>/mall/?siteId=<站点ID>&hostApp=<App标识>
```

| 参数 | 来源 | 说明 |
|---|---|---|
| `siteId` | 聚宝赞分配 | 商城站点 ID；App 不自行生成 |
| `hostApp` | 聚宝赞分配 | App 接入标识，用于选择协议配置；不是登录凭据 |

App 不得在 URL 中附加用户 token、session、手机号等敏感信息。分享或外部打开时是否保留 `hostApp`，由双方根据落地方式确认。

## 最小接入范围

所有接入必须实现 WebView 和登录。其他能力按项目需要确认：

| 能力 | 是否必需 | 文档 |
|---|---:|---|
| WebView 容器与宿主识别 | 是 | [查看](/app/embed-webview) |
| 登录 | 是 | [查看](/app/embed-login) |
| 页面导航与返回 | 按页面范围 | [查看](/app/embed-navigation-share) |
| 分享 | 按业务需求 | [查看](/app/embed-navigation-share) |
| 扫码 | 按业务需求 | [查看](/app/embed-scan) |
| 支付 | 涉及交易时必需 | [查看](/app/embed-payment) |

## 完成标准

接入完成必须同时满足：宿主识别可靠、后台商城登录成功、能力消息格式与版本一致、取消和失败可恢复、支付经后台确认、普通浏览器/微信/小程序不误入 App 链路。

遇到问题请按 [错误处理与联调](/app/embed-troubleshooting) 收集证据。
