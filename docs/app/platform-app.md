# 平台型 App 适配说明

平台型 App 已经拥有自己的用户体系和原生能力协议。平台方提供 SDK、接口文档及测试环境，由我方商城团队编写适配层，并负责 Mall、Ucenter 和业务页面改造。

|---|---:|---:|
| SDK、JSBridge 和错误码文档 | ✓ | 评审 |
| 测试 App、账号和联调环境 | ✓ | 使用 |

| 上线验收 | ✓ | ✓ |

## 可复用与变化部分

`@zan/embed-bridge` 统一承载宿主识别、SDK 准备、登录状态和能力调度。每个平台只实现协议差异：

- SDK 如何加载，Bridge 如何确认可用；
- 平台登录返回哪些临时凭据；
- 分享、扫码、定位和支付调用方式；
- 成功、失败、取消及无回调的含义；
- App 返回 H5 后如何恢复页面状态。

新增平台不能直接复制北仑 CP2 的方法名、成功码或支付参数。应先完成协议评审，再进入开发。

## 接入前置资料

- 平台 SDK/JSBridge 文档及版本范围；
- iOS、Android 的 Bridge 注入方式和时机；
- 登录凭据字段、有效期和服务端校验方式；
- 所需能力的请求、响应、取消和错误示例；
- 测试 App、测试账号、允许域名及联调联系人；
- 发布、灰度和回滚要求。

准备完成后按[开发流程](/app/platform-development)实施。北仑实现见[北仑 CP2 参考实现](/app/platform-beilun-cp2)。
