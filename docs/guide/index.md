# 总览

本站是前端团队的对外文档站，收录各端接入文档与团队技术沉淀。

## 文档地图

| 文档 | 适用场景 | 链接 |
|---|---|---|
| 直播小程序 SDK | 在微信小程序内接入直播播放/开播能力 | [前往](/live-sdk/) |
| H5 商城对接 | 在 App/小程序 webview 中对接 H5 商城页面 | [前往](/h5-mall/) |
| App 对接 | 原生 App 与 H5/小程序之间的桥接通信 | [前往](/app/) |
| 团队技术 | 工程规范、技术分享、工具链 | [前往](/team/) |

## 对接前准备

对接前请先与前端团队确认：

1. 接入场景与目标端（微信小程序 / H5 / 原生 App）
2. 需要的 SDK 版本号
3. 测试环境与联调联系人

## 反馈

文档有问题？[提 issue](https://github.com/FiveWen/zan-docs/issues) 或直接联系前端团队。
